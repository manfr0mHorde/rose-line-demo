# Фото букетов Rose Line для демонстрационной витрины

Демонстрационные карточки используют четыре фотографии, предоставленные пользователем в виде скриншотов публикаций Instagram @rose_line_kz. Фото подготовлены и обрезаны для каталога без интерфейса Instagram.

| Файл в `assets/` | Букет | Цена из скриншота |
| --- | --- | ---: |
| `white-roses.webp` | Белые кустовые розы | 25 000 ₸ |
| `pink-spray-roses.webp` | Розовый комплимент | 22 000 ₸ |
| `ruby-roses.webp` | Малиновая коллекция XL | 60 000 ₸ |
| `blush-roses.webp` | Нежно-розовая коллекция XL | 65 000 ₸ |

Файлы должны находиться в папке `assets/` и называться точно как выше. После загрузки в `main` GitHub Pages отобразит их автоматически: локальные фото имеют приоритет перед внешними ссылками Instagram.

Это неофициальный сайт-концепт. Цены отражают конкретные публикации, не подтверждают актуальное наличие. Для коммерческого использования материалов потребуется согласование с правообладателем.
