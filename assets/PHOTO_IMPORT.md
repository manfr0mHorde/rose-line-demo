# Локальные фотографии Rose Line

В каталоге четыре реальных букета из скриншотов публичных публикаций Instagram @rose_line_kz, предоставленных пользователем:

- Белые кустовые розы — 25 000 ₸
- Розовый комплимент — 22 000 ₸
- Малиновая коллекция XL — 60 000 ₸
- Нежно-розовая коллекция XL — 65 000 ₸

Фотографии сохранены в репозитории в файле `assets/rose-collage.webp` (четыре квадратных кадра 2×2), а CSS `style.css` выбирает нужный кадр по идентификатору товара. Это гарантирует загрузку фотографий без внешних Instagram URL. Ничего дополнительно загружать не требуется. Файл оптимизирован для демонстрационной витрины и имеет ограниченное разрешение.
